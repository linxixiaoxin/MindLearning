## 1. 项目目标

把本地书库变成一个可以公开访问的“问题驱动型知识站”：

```text
用户不是先进来找书，
而是带着一个真实问题进来，
网站帮他找到书、概念、学习路径、行动练习和后续输出。
```

当前最重要的目标不是继续无门禁堆书，而是把 100+ 本公开基础层做稳：

1. 当前 157 本站内书籍能稳定访问。
2. 思想伙伴选配器能完成小样本验证。
3. 发布前能自动检查坏边、缺文件、构建和安全风险。
4. 已扩到 100+ 本，并完成首轮抽样验收；下一步优先修复 8 本源结构化资产问题，再做第二批精选层质量动作。
5. 问题驱动工作流能形成 `真实问题 -> 圆桌推演 -> 行动卡 -> 内容素材 -> 数据/反馈回流` 的闭环。

## 7. 新想法什么时候做

### 学习路径地图

已经完成第一批 3 条站内静态样张，不再只是文档想法。

建议时机：

```text
已完成第 1 条：为什么记了很多笔记，还是写不出来
已完成第 2 条：团队没人说真话，通常不是大家没想法
已完成第 3 条：对方不讲道理时，先别急着摆事实
```

当前三条都已完成：

```text
为什么记了很多笔记，还是写不出来
团队没人说真话，通常不是大家没想法
对方不讲道理时，先别急着摆事实
```

原因：它连接学习笔记、AI 知识系统、内容输出，也适合小红书承接。

### 天命之书 / 思想根基书

现在不要产品化。

建议时机：

```text
至少有 5-10 条真实用户反馈
或你自己完成 2-3 份人工样张后
再考虑做成产品功能。
```

当前只适合保留为：

```text
深度用户人工报告样张
```

对外命名建议先用：

```text
思想根基书
```

不要先叫 `天命之书`，容易被误解成玄学推荐或命定标签。
