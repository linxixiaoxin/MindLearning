# 全书结构

## 主问题

《疯癫与文明》需要回答的是：疯癫、理性、禁闭与医学凝视如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“历史问题化 -> 分类/命名 -> 制度装置 -> 话语规则 -> 身体/主体变化 -> 当代边界”入库，从疯癫、理性、禁闭与医学凝视出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看疯癫、理性、禁闭与医学凝视在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回疯癫、理性、禁闭与医学凝视背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。

## 章节推进

- 愚人船：从麻风病院遗留的排斥空间写起，说明疯癫如何在文艺复兴末期以航行、驱逐、朝圣和图像寓言的形式进入欧洲想象。
- 大禁闭：把疯癫从文艺复兴的流动边界推进到17世纪的收容制度，说明总医院并非医疗机构，而是行政、司法、劳动伦理和道德治理的复合装置。
- 疯人：在禁闭总体中重新辨认疯人的特殊位置：疯癫既被隐藏为耻辱，又被展示为丑闻、兽性和赎罪景观。
- 激情与谵妄：从制度空间转入古典知识内部，分析激情、灵魂、肉体、梦幻、谬误和谵妄如何构成疯癫的解释框架。
- 疯癫诸相：展开古典医学对疯癫类型的整理，显示忧郁症、躁狂症、歇斯底里和疑病症不是自然分类，而是由性质意象、身体模型和道德判断共同编排。
- 医生与病人：分析古典治疗实践中医生与病人的关系，说明治疗并非纯粹技术，而是唤醒、戏剧化、身体干预和道德安排的混合。
- 大恐惧：展示18世纪末非理性如何从禁闭空间中重新返回社会想象，成为传染、腐败、欲望和公共危险的恐惧对象。
- 新的划分：说明18世纪末贫困、人口、劳动、犯罪和疯癫之间的旧混合体如何瓦解，疯癫被从社会经济问题中重新分离出来。
- 精神病院的诞生：收束全书，重估图克和皮内尔的解放神话，说明现代精神病院以宗教、家庭、道德、审判和医生权威重组了疯癫经验。

## 必须保留的概念

- 大禁闭
- 医学凝视
- 正常/异常划分

## 必须保留的关系

- 疯癫、理性、禁闭与医学凝视不是个人感受的同义词，必须放回原书对象关系中理解。
- 谱系权力 / 话语制度型文本不能被压缩成普通方法书。
- 前台内容可以转译，后台结构不能丢失。
