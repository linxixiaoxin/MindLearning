# 全书结构

## 主问题

《最好的告别：关于衰老与死亡，你必须知道的常识》如何帮助读者理解医疗不只是技术，也是一套关系、数据、伦理和照护系统。

## 一句话结构

患者经验 -> 医疗系统 -> 技术与伦理 -> 照护选择

## 核心对象

患者、医生、数据、照护与制度

## 章节推进

- 独立：活到100岁的代价
- 崩溃：接受变老这件事
- 依赖：我们为老做好准备了吗
- 帮助：适应从家到老人院生活的转变
- 更好的生活： 抗击疗养院的三大瘟疫
- 放手：什么时候努力医治，什么时候放弃治疗
- 艰难的谈话：为迎接生命的终点谋求共识
- 勇气：最好的告别
