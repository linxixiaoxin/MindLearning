# 全书结构

## 主问题

《《给你一个团队，你能怎么管？2》》如何帮助管理者从控制任务转向理解人、关系和组织系统。

## 一句话结构

自我觉察 -> 关系结构 -> 团队系统 -> 组织进化

## 核心对象

领导者、团队、反馈、授权与组织学习

## 章节推进

- 团队管理的“宪章”
- 凝聚力是如何打造出来的
- 如何保证高效执行?
- 你必须懂得的团队心理
- 团队沟通也是生产力
- 团队关系锤炼之道
- 如何寻找最好人才?
- 奖惩与激励可以这样做
- 找出团队害群之马
- 提升你的领袖力
- 任何个体需求都要让位于整体利益
- 在双方发生冲突时,管理者要根据“团队宪章”进行裁决。即:在不危害团队利益的前提下,满足个体利益的需求
