# 场景样张：求职与职业转型

> 状态：v0.2 结构化样张
> 关联主线：`真实人生场景入口与人生沙盘模拟`
> 关联模块：`Problem Case`、`思想伙伴选配器`、`学习路径地图`、`能力路径`、`选题中台`

## 1. 本样张要验证什么

验证用户是否愿意从“岗位焦虑”进入一个“能力地图”入口。

核心假设：

- 用户并不总是知道自己适合什么；
- 用户需要岗位全景和能力对照；
- 用户需要转型判断框架，而不是一个单点答案；
- 用户愿意把自己的成长作为一个持续过程。

## 2. 页面目标

让用户在这个入口里看到：

- 我能做什么；
- 市场在要什么；
- 我缺什么；
- 下一步怎么补；
- 如果转型，应该怎么判断。

## 3. 页面结构

### 3.1 顶部

- 标题：求职 / 职业转型
- 一句话说明：先看岗位世界，再看自己的能力地图
- 输入：目标岗位 / 当前状态 / 想转方向

### 3.2 中部

- 岗位全景地图
- 能力对照板
- 转型路径对比
- 个人优势与短板提示

### 3.3 下方

- 推荐 Problem Case
- 推荐思想伙伴视角
- 推荐学习路径
- 推荐能力路径
- 最小行动

## 4. 这个样张的产品表达

### 4.1 不只是换工作

需要明确：

- 转型不是换个标题；
- 求职不是只改简历；
- 真正的关键是能力结构与路径判断。

### 4.2 把成长看成长期过程

这个入口要传达的不是“立刻找到正确岗位”，而是：

- 先知道自己在哪；
- 再知道差什么；
- 再知道怎么补。

## 5. 进入 Problem Case 的方式

可以把这个场景转成如下问题：

- 我适合什么岗位？
- 我到底该不该转型？
- 我当前能力缺口在哪里？
- 我需要补什么，才能进入下一阶段？

## 6. 最小行动

建议样张输出一个最小行动：

- 列出 3 个目标岗位；
- 对照出 3 个关键能力缺口；
- 写出 1 个作品集 / 简历 / 项目改进动作。

## 7. 验收标准

- 用户能看见岗位世界的结构；
- 用户能理解自己的能力短板；
- 页面能引导到 Problem Case；
- 页面能引导到学习路径和能力路径；
- 不把职业选择做成一次性命运判断。

## 9. 页面样张结构

### 9.1 首屏

```text
求职 / 职业转型
先看岗位世界，再看自己的能力地图。

[输入目标岗位 / 当前岗位 / 想转方向]
[我还不知道目标岗位，先从能力和兴趣开始]

你可以先比较：
- 当前能力
- 目标岗位
- 市场要求
- 作品证据
- 转型风险
```

首屏要解决的是“我不知道从哪里开始”的慌张感，而不是立刻给一个职业标签。

### 9.2 中部地图

| 地图区块 | 展示内容 | 目的 |
| --- | --- | --- |
| 岗位世界 | 岗位类型、职责、协作关系、成长路径 | 让用户看见市场结构 |
| 能力对照 | 必备能力、可迁移能力、短板能力 | 把焦虑拆成能力差距 |
| 证据资产 | 简历、作品集、项目、案例、输出 | 让能力变得可证明 |
| 转型路径 | 直接转、内部转、兼职验证、先补能力 | 比较不同风险 |
| 风险提示 | 盲目跳槽、课程囤积、简历叙事断裂 | 防止假努力 |

### 9.3 承接区

| 承接区 | 内容 |
| --- | --- |
| 当前问题命名 | “你现在不是不知道人生方向，而是不知道岗位与能力怎么对齐。” |
| 推荐 Problem Case | 适合岗位判断、是否转型、能力缺口、作品证据、简历叙事 |
| 推荐思想伙伴 | 职业设计、系统思考、教练视角、行为实验 |
| 推荐学习路径 | 能力路径、作品集路径、面试表达路径 |
| 推荐行动 | 选 3 个目标岗位，拆 3 个能力缺口，改 1 个项目证据 |

## 10. 能力地图样例

| 维度 | 需要回答的问题 | 常见误区 | 系统提示 |
| --- | --- | --- | --- |
| 岗位理解 | 这个岗位每天真正做什么？ | 只看岗位标题 | 看职责、交付物、协作对象 |
| 可迁移能力 | 我已有能力哪些能迁过去？ | 以为必须从零开始 | 找出通用能力和行业特定能力 |
| 能力缺口 | 我差的是知识、经验还是作品证据？ | 盲目报课 | 缺什么补什么，先看证据缺口 |
| 叙事表达 | 我的经历如何讲成目标岗位听得懂的话？ | 简历堆经历 | 用“问题-行动-结果-证据”重写 |
| 风险承受 | 我能承受多长空窗和多大收入波动？ | 被理想方向带走 | 把财务、时间和家庭约束放进地图 |
| 验证动作 | 我怎样低成本试一下？ | 想清楚再开始 | 先做小项目、小访谈、小作品 |

## 11. Problem Case 映射

| Problem Case | 用户原话 | 适合输出 |
| --- | --- | --- |
| `career-fit` | “我到底适合什么岗位？” | 岗位地图、能力画像、探索任务 |
| `career-switch-risk` | “我该不该转型？” | 风险对照、路径比较、保底方案 |
| `career-skill-gap` | “我缺什么能力？” | 能力差距表、学习路径、练习任务 |
| `career-proof-assets` | “我没有作品集/项目证据。” | 作品集最小版本、简历证据改写 |
| `career-narrative` | “我的经历太散，不知道怎么讲。” | 职业叙事模板、面试表达练习 |

## 12. 轻量沙盘推演样例

| 路径 | 短期收益 | 中期影响 | 隐藏成本 | 复盘问题 |
| --- | --- | --- | --- | --- |
| 立刻投递目标岗位 | 快速获得市场反馈 | 能知道简历是否被认可 | 容易被拒绝打击，且反馈不一定具体 | 我能从 10 次投递里提取什么信号？ |
| 先做作品集 | 能把能力变成证据 | 转型叙事更扎实 | 如果没有截止日期，容易拖延 | 7 天内能完成哪个最小作品？ |
| 先内部转岗 | 风险低，能保留收入 | 可以借公司场景积累证据 | 受组织机会限制 | 公司内部有没有可借力项目？ |
| 先学习补课 | 心理上更安心 | 能补基础知识 | 容易囤课不产出 | 学完后要交付什么作品？ |

## 13. 继续探索模块

| 模块 | 输出样例 |
| --- | --- |
| 思想伙伴 | “教练视角：先不要问我适合什么，先问我可以用什么小实验验证。” |

## 14. 内容切口

| 切口 | 标题方向 |
| --- | --- |
| 岗位焦虑 | 你不是没有方向，你是还没看懂岗位世界 |
| 能力缺口 | 转型前别急着报课，先分清你缺的是哪种能力 |
| 作品证据 | 简历写不动，往往是因为你没有可证明的交付物 |
| 转型风险 | 转型不是一跳，而是一组低成本验证 |
| 职业叙事 | 经历很散的人，最需要先重写自己的职业故事 |

- 有完整 `LifeScene` 场景卡；
