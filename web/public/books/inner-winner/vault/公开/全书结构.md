# 全书结构

## 主问题

《你骨子里是个牛人》如何帮助读者把成长愿望拆成可练习、可反馈、可持续的行动系统。

## 一句话结构

目标 -> 方法 -> 练习 -> 反馈 -> 身份变化

## 核心对象

学习、时间、习惯、成长和行动

## 章节推进

- ONE 你很强大,从出生到现在
- 大多数人都活在对他人看法的错觉中
- 你是骗不了宇宙的
- 你想要的生活就在这里
- 摒弃那些拖我们后腿的成见
- 努力成为自己的忠实粉丝
- TWO重要的是,对你来说什么是真的
- 首先考虑自身的需求
- 他人对你的看法和你一点关系也没有
- 试着做一天外星人
- 荒野深处裹腰布的男子
- THREE能量本就与生俱来
