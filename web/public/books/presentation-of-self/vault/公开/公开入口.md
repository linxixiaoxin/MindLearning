# 日常生活中的自我呈现

## 这本书先解决什么

《日常生活中的自我呈现》需要回答的是：互动场景、角色、观众、前台/后台与印象管理如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“互动场景 -> 角色期待 -> 前台/后台 -> 印象管理 -> 尴尬修复 -> 身份风险”入库，从互动场景、角色、观众、前台/后台与印象管理出发，保留概念、机制、场景、证据和误用边界。
