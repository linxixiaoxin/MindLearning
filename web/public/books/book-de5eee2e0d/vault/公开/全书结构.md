# 全书结构

## 主问题

《内在成长：心智成熟的四个思维习惯》如何帮助读者理解内在模式、情绪反应和关系中的自我位置。

## 一句话结构

情绪感受 -> 内在模式 -> 关系边界 -> 自我修复

## 核心对象

情绪、身体、关系、自我模式和意义

## 章节推进

- 深度思考,了解本质
- 摆脱过度猜想
- 让思维停留在当下正在发生的事情上
- 可能性思考的力量
- 理性分析,从容应对
- 学会暂停,然后赋予自己一个新身份
- 把问题缩小到真正具体的一件事上
- 解决方案不止一个且无须立即制定
- 脑力激荡,把自身能量集中到一点
- 设立破解密码
- 內观思维,修炼自身
- 强化内在沟通系统,善于与自己对话
