# 福格行为模型

## 这本书先解决什么

如何不靠意志力硬撑，而是通过动机、能力和提示设计，让好行为更容易发生。

## 一句话结构

愿望不会直接改变生活，具体行为才会。；行为发生取决于动机、能力和提示的同时出现。；与其提高意志力，不如降低行为难度。；微小行为更容易启动，并能积累身份感。；庆祝和积极情绪会让习惯更容易留下来。
