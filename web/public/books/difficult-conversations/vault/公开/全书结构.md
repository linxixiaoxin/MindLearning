# 全书结构

## 主问题

《高难度谈话》如何帮助读者把混乱表达转成能被理解、能推进关系的对话结构。

## 一句话结构

事实 -> 感受 -> 需要 -> 请求 -> 关系修复

## 核心对象

对话、关系、边界和共识

## 章节推进

- 分问题
- 挑选出三种谈话
- 分向学习型姿态转变
- 停止争论谁对谁错:了解他人的故事
- 不要设定对方的意图:让矛盾与意图无关
- 放弃指责:将归责系统图表化
- 掌握你的情绪——不然,它们将会成为你的主宰
- 为你的自我认知做铺垫:问问你自己,什么受到了威胁
- 分创造学习型谈话
- 你的目的是什么
