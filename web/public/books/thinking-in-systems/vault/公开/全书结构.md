# 全书结构

## 主问题

《系统之美》如何帮助读者看见判断背后的模型、偏差和系统结构。

## 一句话结构

问题定义 -> 机制识别 -> 模型比较 -> 决策校正

## 核心对象

心智、模型、偏差、系统和选择

## 章节推进

- 分系统的结构和行为第1章系统之基础总体大于部分之和
- 系统大观园单存量系统
- 分系统思考与我们第3章系统之美:系统的3大特征适应力
- 系统之奇:系统的6大障碍别被表象所迷惑
- 系统之危与机:系统的8大陷阱与对策政策阻力:治标不治本
- 分改变系统第6章系统之杠杆点:系统的12大变革方式 12.数字:包括各种常数和参数
- 缓冲器:比流量力量更大、更稳定的存量
- 存量—流量结构:实体系统及其交叉节点
- 时间延迟:系统对变化做出反应的速度
- 调节回路:试图修正外界影响的反馈力量
- 增强回路:驱动收益增长的反馈力量
- 信息流:谁能获得信息的结构
