# 终身学习：10个你必须掌握的未来生存法则

## 这本书先解决什么

如何让学习和成长成为贯穿一生的取向，而不是阶段性的任务。

## 一句话结构

全书用十组“为上/次之”的价值取舍，帮助读者从过去、经验、回报、赞誉、成功、劳累、地位、安乐、金钱、答案中移开，转向未来、学习、付出、表现、感恩、乐趣、合作、信心、目标和问题。
