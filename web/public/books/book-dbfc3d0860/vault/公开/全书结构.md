# 全书结构

## 主问题

《这才是心理学》如何帮助读者看见判断背后的模型、偏差和系统结构。

## 一句话结构

问题定义 -> 机制识别 -> 模型比较 -> 决策校正

## 核心对象

心智、模型、偏差、系统和选择

## 章节推进

- 心理学充满生机(在科学阵营里表现不俗)
- 可证伪性:如何打败头脑中的小精灵
- 操作主义和本质主义:“但是,博士,这到底是什么意思?”
- 见证和个案研究证据:安慰剂效应和了不起的兰迪
- 相关和因果:用“烤箱法”避孕
- 让一切置于控制之下:聪明汉斯的故事
- “但这不是真实的生活!”:“人为性”批评与心理学
- 避免爱因斯坦综合征:聚合性证据的重要性
- 打破“神奇子弹”的神话:多重原因的问题
- 人类认知的阿喀琉斯之踵:概率推理
- 偶然性在心理学中扮演的角色
- 不招人待见的心理学
