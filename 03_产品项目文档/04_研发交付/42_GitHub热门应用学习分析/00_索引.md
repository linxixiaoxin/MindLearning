## 1. 文件夹定位

这个目录不是普通“收藏夹”，而是面向本项目的外部样本库。

每次收录 GitHub 项目时，优先回答四个问题：

1. 它解决的核心用户问题是什么。
2. 它为什么能获得大量收藏或社区共识。
3. 对 `book-kb-multi`、思想伙伴工具、小红书内容生产或本地知识资产流水线有什么可借鉴点。
4. 哪些东西不适合照搬，避免项目膨胀。
