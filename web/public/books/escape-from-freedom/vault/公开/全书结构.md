# 全书结构

## 主问题

《逃避自由》需要回答的是：自由焦虑、孤独、权威依附、社会性格与逃避机制如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“自由处境 -> 焦虑/孤独 -> 权威依附 -> 社会性格 -> 服从/不服从的心理代价”入库，从自由焦虑、孤独、权威依附、社会性格与逃避机制出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看自由焦虑、孤独、权威依附、社会性格与逃避机制在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回自由焦虑、孤独、权威依附、社会性格与逃避机制背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。

## 章节推进

- 个人之出现与自由之暧昧：用个人之出现与自由之暧昧确定这本书进入问题的入口，先钉住自由焦虑、孤独、权威依附、社会性格与逃避机制的出场条件。
- 宗教改革时期之自由：把宗教改革时期之自由作为分析对象的转折点，观察自由焦虑、孤独、权威依附、社会性格与逃避机制如何从背景变成可描述的结构。
- 现代人的两种自由观念：通过现代人的两种自由观念整理关键概念之间的压力，避免把本章读成孤立观点摘录。
- 逃避的心理机构：借逃避的心理机构补足证据层，让社会心理 / 自由服从型不只停留在术语解释。
- 自由与民主：以自由与民主收束前面章节留下的边界问题，给后续主题 K 提供判断语言。

## 必须保留的概念

- 自由焦虑
- 权威依附
- 自动化一致

## 必须保留的关系

- 自由焦虑、孤独、权威依附、社会性格与逃避机制不是个人感受的同义词，必须放回原书对象关系中理解。
- 社会心理 / 自由服从型文本不能被压缩成普通方法书。
- 前台内容可以转译，后台结构不能丢失。
