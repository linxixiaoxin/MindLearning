# 全书结构

## 主问题

《高敏感是种天赋》如何帮助读者理解内在模式、情绪反应和关系中的自我位置。

## 一句话结构

情绪感受 -> 内在模式 -> 关系边界 -> 自我修复

## 核心对象

情绪、身体、关系、自我模式和意义

## 章节推进

- 激发灵感的活动
- 外出活动
- 刺激过度时，做一些对身体有益的活动
- 亲密接触大自然
- 表达自己
- 创造性活动
- 愉悦自己的感官
- 放松灵魂
