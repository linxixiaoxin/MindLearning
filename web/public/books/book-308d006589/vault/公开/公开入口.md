# 空间的生产

## 这本书先解决什么

《空间的生产》需要回答的是：社会空间、资本、制度、日常实践与空间表征如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“空间经验 -> 空间秩序 -> 身体感受 -> 社会关系/权力安排 -> 自我安放方式”入库，从社会空间、资本、制度、日常实践与空间表征出发，保留概念、机制、场景、证据和误用边界。
