# 全书结构

## 主问题

《无聊的魅力》如何把日常经验重新命名，让读者换一种方式观看生活。

## 一句话结构

日常困境 -> 场景观察 -> 哲学参照 -> 重新观看

## 核心对象

现代生活中的感受与场景

## 章节推进

- 这种不忠实并不一定体现为恶劣的谎言或夸大事实。它只是意味着努力猜测克洛艾想要什么，以便于我按照角色要求说出正确的台词
- 第一道菜上来了，菜肴摆放得极其精致，就像地道的法国花园那样匀称整齐
- 克洛艾现在面临着两难选择，到吃甜点的时候了，虽然她只能选择一样，却有着不止一种欲望
- 说完这些，她把嘴唇贴上了我的嘴唇，开始了人类历史上最长久最美妙的亲吻
- 苏黎世对世人具有鲜明的教育意义，它让我们明白，在一个无聊的资产阶级城市里，我们可以获得真正富有想象力和人性的生活
- 幽默不仅是攻击地位显赫之人的有效工具，而且能够帮助我们理解并缓解我们自己的身份焦虑
