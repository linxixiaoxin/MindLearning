## 3. 当前样张结构

### 3.1 笔记到输出

| 层级 | 名称 | 作用 |
| --- | --- | --- |
| L0 | 问题定向 | 把“写不出来”改写为“笔记没有形成输出结构” |
| L1 | 根概念 | 建立结构性张力、成果导向、反证过滤等概念抓手 |
| L2 | 主书路径 | 先打开《最小阻力之路》，把输出理解成结构生成 |
| L3 | 校正路径 | 防止把问题误判成自律不足或天赋不足 |
| L4 | 练习路径 | 15 分钟完成“3 条笔记成卡” |
| L5 | 输出路径 | 产出“问题-概念-例子-一句话结论卡” |

### 3.2 团队真话

| 层级 | 名称 | 作用 |
| --- | --- | --- |
| L0 | 问题定向 | 把“没人说真话”改写为“共享意义池不安全、不完整、没有行动出口” |
| L1 | 根概念 | 建立安全感、共享意义池、沉默与暴力、渴求共识等抓手 |
| L2 | 主书路径 | 用《关键对话》搭出安全感、事实观点、行动收束的对话骨架 |
| L3 | 校正路径 | 防止把沉默简单归因成大家没想法或没有担当 |
| L4 | 练习路径 | 10 分钟低风险真话入口 |
| L5 | 输出路径 | 产出“安全感-顾虑-系统原因-下一步动作卡” |

### 3.3 摆事实前

| 层级 | 名称 | 作用 |
| --- | --- | --- |
| L0 | 问题定向 | 把“对方不讲道理”改写为“事实、故事、情绪和安全感纠缠” |
| L1 | 根概念 | 建立从事实到故事、感觉正确、为了学习而倾听、社会疼痛等抓手 |
| L2 | 主书路径 | 用《关键对话》练习拆分事实、故事、感受和请求 |
| L3 | 校正路径 | 防止自己陷入简化故事、默认正确感和赢辩论模式 |
| L4 | 练习路径 | 用“事实-故事-确认问题”替代直接摆事实 |
| L5 | 输出路径 | 产出“事实-故事-安全感-下一句话卡” |
