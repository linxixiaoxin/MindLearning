# 全书结构

## 主问题

《关于说话的一切》如何帮助读者把混乱表达转成能被理解、能推进关系的对话结构。

## 一句话结构

事实 -> 感受 -> 需要 -> 请求 -> 关系修复

## 核心对象

对话、关系、边界和共识

## 章节推进

- 意义 无限复杂的语言游戏
- 关系 你不是嘴笨，是心钝
- 内容 说到点子上
- 场景与内容 在任何场合都能好好说话
- 关于“倾听—回应”的一切
- 一个关于“说话”的整合框架
- 进入世界的练习
- 逻辑 起点与终点
- 演绎 从AEIO到AlphaGo
- 归纳 经验暗海上的浮木
- 类比 思维之火与概念之网
- 溯因与辩证 能言与善辩
