## 5. 任务进入开发前检查

任何任务从 `Backlog` 进入 `Ready` 前，检查：

- 是否有产品需求来源，或明确是 bug / 技术债。
- 是否知道主要改动文件。
- 是否影响 `registry/books.json`、书籍 bundle、topic bundle 或工具数据。
- 是否需要更新数据结构文档。
- 是否需要新增或修改 API / bridge 协议。
- 是否需要新增测试用例或发布前检查。
- 是否需要记录 ADR。

如果只是 bug 修复，可以直接进入本文和 [35_缺陷与技术债记录](./35_缺陷与技术债记录.md)。
