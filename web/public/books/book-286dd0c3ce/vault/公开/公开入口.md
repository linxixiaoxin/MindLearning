# 规训与惩罚

## 这本书先解决什么

《规训与惩罚》需要回答的是：身体、刑罚、规训、监狱与全景敞视如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“公开酷刑 -> 惩罚改革 -> 驯顺身体 -> 规训技术 -> 全景敞视 -> 监狱社会”入库，从身体、刑罚、规训、监狱与全景敞视出发，保留概念、机制、场景、证据和误用边界。
