# 全书结构

## 主问题

《福柯》需要回答的是：福柯思想路线、作品边界和术语坐标如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“作者生平 -> 主要作品 -> 方法转换 -> 疯癫/惩罚/现代性主题 -> 阅读边界”入库，从福柯思想路线、作品边界和术语坐标出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看福柯思想路线、作品边界和术语坐标在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回福柯思想路线、作品边界和术语坐标背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。
