# 全书结构

## 主问题

《如何快速了解一个行业 (肖璟)》如何提供可复用的概念、问题和场景解释。

## 一句话结构

主题识别 -> 概念整理 -> 场景调用 -> 内容转译

## 核心对象

书中的核心概念、场景和表达资源

## 章节推进

- 分行研框架篇
- 主要讲的是,如何评估商业模式的可行性。如果说可行性是判断企业能不能从0到1,那么本章将要讲的规模性就是用来判断企业能不能从1到100

- 渗透率

- 稳固渠道
- 提高转换成本
