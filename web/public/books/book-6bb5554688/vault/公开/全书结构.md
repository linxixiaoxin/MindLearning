# 全书结构

## 主问题

《团队是设计出来的》如何帮助管理者从控制任务转向理解人、关系和组织系统。

## 一句话结构

自我觉察 -> 关系结构 -> 团队系统 -> 组织进化

## 核心对象

领导者、团队、反馈、授权与组织学习

## 章节推进

- 想成功,先设计你的团队
- 见证:从上海到约翰内斯堡
- 团队属性:“为什么羊总被狼吃掉?”
- 忍耐力:每个人都需要
- 协同作战:不要让个人的力量主导团队
- 永不认输:每次失败,都是一个全新的起点
- 团队定位:找到适合自己的“草原”
- 好团队的基础:10条狼性元素
- 合作:集体行动,进退有序
- 执着:对目标坚定不移,向往成功
- 忠诚:每个人都对企业和上司绝无二心
- 耐心:目光长远,按部就班,不急于求成
