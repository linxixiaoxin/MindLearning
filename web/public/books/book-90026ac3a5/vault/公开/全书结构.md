# 全书结构

## 主问题

《写给无神论者》如何把日常经验重新命名，让读者换一种方式观看生活。

## 一句话结构

日常困境 -> 场景观察 -> 哲学参照 -> 重新观看

## 核心对象

现代生活中的感受与场景
