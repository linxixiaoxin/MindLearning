# 空间的诗学

## 这本书先解决什么

《空间的诗学》需要回答的是：家宅、角落、抽屉、鸟巢、贝壳与亲密空间想象如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“空间经验 -> 意象 -> 记忆/想象 -> 安全感/亲密性 -> 自我安放”入库，从家宅、角落、抽屉、鸟巢、贝壳与亲密空间想象出发，保留概念、机制、场景、证据和误用边界。
