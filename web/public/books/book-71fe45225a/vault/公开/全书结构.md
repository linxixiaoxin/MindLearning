# 全书结构

## 主问题

《知识考古学（4版）》需要回答的是：话语、陈述、档案、知识形成规则与考古学描述如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“话语对象 -> 陈述规则 -> 档案系统 -> 知识形成 -> 方法边界”入库，从话语、陈述、档案、知识形成规则与考古学描述出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看话语、陈述、档案、知识形成规则与考古学描述在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回话语、陈述、档案、知识形成规则与考古学描述背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。

## 章节推进

- 导论：用导论确定这本书进入问题的入口，先钉住话语、陈述、档案、知识形成规则与考古学描述的出场条件。
- 话语的规则性：把话语的规则性作为分析对象的转折点，观察话语、陈述、档案、知识形成规则与考古学描述如何从背景变成可描述的结构。
- 陈述与档案：通过陈述与档案整理关键概念之间的压力，避免把本章读成孤立观点摘录。
- 考古学的描述：借考古学的描述补足证据层，让谱系权力 / 方法论底座不只停留在术语解释。
- 结论：以结论收束前面章节留下的边界问题，给后续主题 K 提供判断语言。

## 必须保留的概念

- 话语
- 陈述
- 档案

## 必须保留的关系

- 话语、陈述、档案、知识形成规则与考古学描述不是个人感受的同义词，必须放回原书对象关系中理解。
- 谱系权力 / 方法论底座文本不能被压缩成普通方法书。
- 前台内容可以转译，后台结构不能丢失。
