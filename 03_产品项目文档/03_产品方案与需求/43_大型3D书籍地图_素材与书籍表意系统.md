# 大型 3D 书籍地图：素材与书籍表意系统

> 创建时间：2026-05-02  
> 关联页面：`/tools/space-browser`  
> 关联代码：`web/src/components/SpaceAtlas3D.vue`  
> 上游文档：`40_大型3D书籍地图重构调研与素材方案_2026-05-02.md`

## 1. 当前问题

现在动态和镜头已经接近“大地图浏览”，但视觉内容还停留在：

```text
彩色岛屿 + 书名牌 + 少量程序化地标
```

它的问题是：

- 岛屿像色块，不像真实的 3D 场景。
- 书籍像“名字牌”，缺少每本书的气质。
- 不同领域之间只靠颜色区分，不靠物件语义区分。
- 用户远看时只看到标题，无法一眼判断“这里是什么世界”。

下一步要从“书名地图”升级为：

> **书籍主题世界 + 领域地貌 + 单书隐喻物件**

## 2. 素材来源优先级

### 2.1 第一优先级：Quaternius

来源：

- Fantasy Props MegaKit：https://quaternius.itch.io/fantasy-props-megakit
- Quaternius itch 主页：https://itch.io/profile/quaternius

为什么适合：

- `Fantasy Props MegaKit` 有 200+ 中世纪/奇幻道具，包含 furniture、tools、weapons、books、potions、breakables 等类别。
- 页面明确写了可用于 personal、educational、commercial projects，许可证为 CC0。
- 提供 `.FBX`、`.OBJ`、`.glTF`，适合 Three.js。
- 道具很适合做“知识地图”的隐喻：书堆、药水、桌子、箱子、工具、摊位、家具、卷轴感物件。

推荐用途：

- 单本书的代表物件。
- 心理疗愈、方法练习、认知决策等岛屿上的小道具。
- 近景书籍详情的“主题雕塑”。

优先下载：

- `Fantasy Props MegaKit[Standard].zip`
- 可先只挑 20-30 个 `.glTF` / `.glb` 进项目。

### 2.2 第二优先级：Kenney

来源：

- 3D 分类页：https://kenney.nl/assets/category:3D
- Car Kit 示例页：https://kenney.nl/assets/car-kit

为什么适合：

- Kenney 的 3D 分类页有 Factory Kit、Car Kit、Platformer Kit、Modular Dungeon Kit、Pirate Kit、Fantasy Town Kit、City Kit 等。
- 单个资产页会标注 License，例如 Car Kit 标注 Creative Commons CC0。
- 风格统一、低模、轻量，适合 WebGL。

推荐用途：

- 岛屿基础地貌：树、道路、房子、工厂、城市、桥、平台、车辆。
- 不同领域的大型地标：城市、工坊、港口、道路、地牢、海盗/航海元素。
- 地图边缘装饰和路径系统。

优先挑选：

- `Fantasy Town Kit`：生活/关系/成长类岛屿。
- `Modular Dungeon Kit`：困境、卡住、心理阴影的隐喻空间。
- `Factory Kit`：系统思考、生产流程、内容中台。
- `City Kit (Roads)`：路径、选择、转型、人生路线。
- `Pirate Kit`：探索、旅行、未知水域。

### 2.3 第三优先级：Poly Pizza

来源：

- Explore：https://poly.pizza/explore

为什么适合：

- 有大量 low poly 3D models。
- 支持 OBJ、FBX、GLTF 等格式。
- 可按关键词找更具体的模型，比如 pyramid、lighthouse、book、bridge、compass、mask、mirror、desk。

注意：

- Poly Pizza 上每个模型许可证可能不同，不能默认全站 CC0。
- 只收录单个模型时，要记录模型页面、作者、license。

推荐用途：

- 补齐 Quaternius / Kenney 没有的“特定隐喻物件”。
- 例如：金字塔、骆驼、灯塔、面具、天平、钥匙、门、望远镜、罗盘。

### 2.4 环境与材质：Poly Haven / ambientCG

来源：

- Poly Haven：https://polyhaven.com/
- ambientCG：https://ambientcg.com/

为什么适合：

- Poly Haven 标注资产为 CC0，可用于任何目的。
- ambientCG 明确说明所有资产采用 Creative Commons CC0，可商用且无需署名。
- 适合补充 HDRI、地面材质、木头、石头、布料、沙地、水面、岩石纹理。

推荐用途：

- 地面 PBR 材质。
- 岛屿边缘、道路、水面、木质书架、石台材质。
- 后续如果做更真实光照，可用 Poly Haven HDRI。

## 3. 不再把书做成“名字牌”

书籍在地图里的表现应该分 3 层：

| 视角层级 | 显示内容 | 目的 |
| --- | --- | --- |
| 远景 | 领域地貌 + 大地标 + 少量代表物件 | 让用户知道这里是什么世界 |
| 中景 | 单书隐喻物件 + 短名标签 | 让用户知道这本书的大概气质 |
| 近景 | 完整书名 + 简介 + 标签 + 相关路径 | 确认身份和进入阅读 |

也就是说：

```text
远景不要显示一排书名。
中景不要只显示书名。
近景才把书名作为确认信息。
```

## 4. 领域级地貌设计

### 4.1 心理疗愈群岛

关键词：

- 情绪、身体、自我理解、创伤、敏感、内在小孩、恢复。

地貌：

- 柔和森林岛。
- 树洞、镜子、灯、温室、帐篷、修复工具。
- 水面和石径更多，避免尖锐建筑。

可用素材：

- Quaternius：books、potions、furniture、plants、small props。
- Kenney：Fantasy Town Kit、Platformer Kit、树和自然物。
- ambientCG：moss、wood、ground、stone textures。

单书形式：

- 不是一本书，而是一个“小修复场景”。
- 例：镜子 + 灯 + 打开的书，表示自我觉察。
- 例：被支架托住的树苗，表示恢复和照护。

### 4.2 认知决策高地

关键词：

- 判断、误区、系统、偏差、证据、模型。

地貌：

- 高台、阶梯、观测塔、齿轮、天平、迷宫、分岔路。
- 颜色可偏砂岩、铜、灰蓝。

可用素材：

- Kenney：Factory Kit、City Roads。
- Quaternius：tools、tables、books、crates。
- Poly Pizza：scale、compass、gear、maze-like props，如有合适 license。

单书形式：

- 《思考，快与慢》：双层齿轮 / 两个速度不同的钟盘 / 分岔控制台。
- 判断偏差类：歪斜天平 + 放大镜。
- 系统思考类：管道、齿轮和仪表盘。

### 4.3 沟通关系港

关键词：

- 表达、倾听、边界、亲密关系、冲突修复。

地貌：

- 港口、桥、两座小屋、圆桌、门廊、信箱、绳结。
- 多用“连接但有距离”的空间隐喻。

可用素材：

- Kenney：Fantasy Town Kit、Pirate Kit、Roads。
- Quaternius：tables、chairs、market stalls、small props。
- Poly Pizza：bridge、door、mailbox、speech-like signs。

单书形式：

- 《非暴力沟通》：两张椅子 + 圆桌 + 四颗小石子，分别代表观察、感受、需要、请求。
- 亲密关系类：桥的一端亮起，另一端留有边界线。
- 边界类：半开的门 + 清晰门槛。

### 4.4 组织与成长山脉

关键词：

- 领导力、复杂度、教练、组织、角色升级。

地貌：

- 山脉、阶梯、训练营、旗帜、塔、会议桌、工坊。
- 高低差要明显，体现成长阶段。

可用素材：

- Kenney：Factory Kit、Fantasy Town Kit、City Kit。
- Quaternius：tables、tools、banners、training props。

单书形式：

- 领导力类：阶梯塔 + 旗帜。
- 教练类：训练场 + 路标。
- 组织复杂度类：多层平台 + 连接桥。

### 4.5 学习方法平原

关键词：

- 习惯、练习、输出、复利、方法、学习路径。

地貌：

- 道路、农田、工坊、练习靶场、流水线、日历碑。
- 重点是“重复、路径、积累”。

可用素材：

- Kenney：Platformer Kit、Roads、Factory Kit。
- Quaternius：tools、crates、workbench、books。

单书形式：

- 习惯类：连续脚印 / 日历块 / 小齿轮。
- 学习类：工坊桌 + 笔记本 + 练习靶。
- 输出类：传送带 / 发布台 / 小舞台。

### 4.6 健康照护海岸

关键词：

- 生命、医疗、照护、告别、身体、脆弱。

地貌：

- 海岸、灯塔、码头、医疗帐篷、花园、安静小屋。
- 气质应该稳、轻、留白。

可用素材：

- Kenney：Pirate Kit、Fantasy Town Kit、自然物。
- Quaternius：beds、tables、plants、small props。
- Poly Haven / ambientCG：水面、木头、石头、布料纹理。

单书形式：

- 照护类：灯塔 + 小屋。
- 医疗认知类：诊疗桌 + 放大镜。
- 告别类：码头尽头 + 灯。

## 5. 单本书表意卡：从“书名”到“物件组合”

每本书应该有一个 `visualProfile`：

```ts
type BookVisualProfile = {
  world: 'mind' | 'thinking' | 'dialogue' | 'leadership' | 'practice' | 'care'
  form: 'object-shrine' | 'mini-scene' | 'tool-station' | 'landmark' | 'path-node'
  primaryProp: string
  secondaryProps: string[]
  motionHint: 'pulse' | 'turn' | 'open' | 'glow' | 'none'
  labelLevel: 'short' | 'full-on-focus'
}
```

### 5.1 表意形式类型

| 类型 | 适合书籍 | 地图呈现 |
| --- | --- | --- |
| object-shrine | 概念强、理论强的书 | 一个核心物件立在小底座上 |
| mini-scene | 场景/关系/心理类书 | 2-4 个物件组成一幕小场景 |
| tool-station | 方法、训练、行动类书 | 工作台、工具架、练习台 |
| landmark | 权威理论/母书/总纲书 | 小塔、观测台、门、碑 |
| path-node | 学习路径、成长路径类书 | 路标、阶梯、桥、驿站 |

### 5.2 示例映射

| 书 / 主题 | 不推荐 | 推荐表意 |
| --- | --- | --- |
| 《人类木马程序》 | 只放书名牌 | 木马 / 傀儡线 / 开锁工具 / 代码碎片，表示“被植入的自动程序” |
| 《高敏感是种天赋》 | 只放书名牌 | 透明温室 / 感应天线 / 柔软屏障 / 小灯，表示“敏感但可被安放” |
| 《非暴力沟通》 | 只放书名牌 | 两把椅子 + 圆桌 + 四枚石子，表示沟通四要素 |
| 《思考，快与慢》 | 只放书名牌 | 双钟盘 / 双齿轮 / 分岔控制台，表示两套系统 |
| 领导力书籍 | 只放书名牌 | 阶梯塔 / 旗帜 / 训练场，表示成长高度 |
| 学习方法书 | 只放书名牌 | 工坊台 / 日历块 / 连续脚印，表示练习与复利 |
| 健康照护书 | 只放书名牌 | 灯塔 / 小屋 / 医疗桌 / 花园，表示照护与安顿 |

## 6. 素材接入结构

建议目录：

```text
web/public/atlas-assets/
  models/
    quaternius/
    kenney/
    poly-pizza/
  textures/
    ambientcg/
    polyhaven/
  licenses/
    quaternius_fantasy-props-megakit.md
    kenney_fantasy-town-kit.md
    poly-pizza_selected-models.md
  manifest.json
```

`manifest.json` 示例：

```json
{
  "assets": [
    {
      "id": "prop-mirror-01",
      "source": "Quaternius Fantasy Props MegaKit",
      "path": "/atlas-assets/models/quaternius/mirror.glb",
      "license": "CC0-1.0",
      "usage": ["mind", "self-reflection"]
    }
  ]
}
```

## 7. 下一步实施建议

第一轮不要把所有书都做完。先做 12 个代表物：

1. 心理疗愈：镜子、灯、树洞、温室。
2. 认知决策：天平、齿轮、观测塔、分岔路。
3. 沟通关系：圆桌、桥、门槛、信箱。
4. 组织成长：阶梯塔、旗帜、训练场。
5. 学习方法：工坊台、日历块、路标。
6. 健康照护：灯塔、小屋、码头、医疗桌。

然后给 6 本代表书做 `visualProfile`，验证：

- 远景能否一眼看出领域；
- 中景能否不看书名也猜到书的气质；
- 近景书名和简介是否只是确认，而不是全部信息。

## 8. 结论

下一版不应该继续做“3D 书名牌”。更好的方向是：

> 每本书是一个可识别的隐喻物件 / 小场景，书名只是近景确认信息。

素材上优先用 Quaternius 和 Kenney 做统一低模世界；Poly Pizza 只作为缺口补充；Poly Haven 和 ambientCG 负责纹理、地面和光照。
