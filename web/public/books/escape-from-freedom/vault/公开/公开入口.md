# 逃避自由

## 先用它看什么

这本书适合处理一个反直觉问题：人获得自由以后，为什么反而会害怕、孤独，并主动把自己交给权威、从众或机械化的生活方式。

## 进入路径

先看“自由处境 -> 焦虑孤独 -> 权威依附 -> 社会性格 -> 服从与不服从的代价”这条链。它可以连接职场服从、关系依附、舆论从众和自我选择恐惧。

## 公开边界

不要把它读成“自由不好”。弗洛姆真正追问的是：一个人如何在不逃回权威的情况下，发展出能承担自由的自我。
