# 大型 3D 书籍地图：自制资产包说明

> 日期：2026-05-02  
> 关联页面：`/tools/space-browser`  
> 关联脚本：`web/scripts/build-redbook-atlas-assets.mjs`  
> 资产目录：`web/public/atlas-assets/models/redbook/custom-glb/`

## 一、为什么要自制

上一版主要问题不是 Three.js 能力不足，而是通用素材包无法表达书籍本身：Kenney 资产适合做树、路、房子、码头、灯等环境物件，但很难表达《人类木马程序》《思考，快与慢》《非暴力沟通》这类书的独特概念。

因此本轮新增 RedBook 自制资产包，把“书籍入口”从通用书封/色块提升为项目自己的 3D 隐喻物。

## 二、第一批资产

| 文件 | 表达对象 |
|---|---|
| `trojan-program.glb` | 木马程序、自动化脚本、隐藏触发器 |
| `sensitivity-greenhouse.glb` | 高敏感、情绪安放、柔软边界 |
| `dialogue-table.glb` | 非暴力沟通、关系对话、四步表达 |
| `dual-clock-decision.glb` | 思考快慢、双系统、判断切换 |
| `stair-tower-growth.glb` | 领导力、成长阶梯、复杂度上升 |
| `practice-workbench.glb` | 学习方法、练习、工具化输出 |
| `care-lighthouse.glb` | 医疗照护、生命海岸、告别与安顿 |
| `bridge-door-boundary.glb` | 边界、门槛、连接与拒绝 |
| `compass-path.glb` | 旅行、路径、观看方式 |
| `mirror-lamp-self.glb` | 自我探索、镜子、照亮盲区 |

## 三、接入原则

- 重点书优先使用自制 GLB，不再默认使用同一套书封。
- 通用 Kenney 资产只做环境，不再承担核心书籍表意。
- 后续每增加一本重点书，应先写 `visualProfile`，再决定是复用现有资产还是生成新资产。

## 四、下一步

下一轮建议先为 6 本代表书补显式视觉档案：

- 《人类木马程序》：`trojan-program`
- 《人生模式》：`mirror-lamp-self` 或新增“模式罗盘/底层操作台”
- 《思考，快与慢》：`dual-clock-decision`
- 《非暴力沟通》：`dialogue-table`
- 《高敏感是种天赋》：`sensitivity-greenhouse`
- 医疗照护类：`care-lighthouse`
