# 全书结构

## 主问题

《十四堂人生创意课》如何帮助读者理解内在模式、情绪反应和关系中的自我位置。

## 一句话结构

情绪感受 -> 内在模式 -> 关系边界 -> 自我修复

## 核心对象

情绪、身体、关系、自我模式和意义
