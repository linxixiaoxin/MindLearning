# 全书结构

## 主问题

《韩炳哲作品系列（套装共9册）》需要回答的是：绩效、透明、倦怠、数字群体与现代主体如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“时代症候 -> 主体状态 -> 媒介/绩效机制 -> 情绪后果 -> 诊断边界”入库，从绩效、透明、倦怠、数字群体与现代主体出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看绩效、透明、倦怠、数字群体与现代主体在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回绩效、透明、倦怠、数字群体与现代主体背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。
