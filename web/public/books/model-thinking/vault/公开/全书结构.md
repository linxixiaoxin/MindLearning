# 全书结构

## 主问题

复杂现实中的判断为什么总会被单一解释带偏，以及人如何用多个模型更接近真实。

## 一句话结构

全书先证明复杂世界不能只靠常识，再解释模型的用途，随后把多模型思维推进到人类行为、网络、路径依赖和系统演化，最后收口到一种更稳的判断方式。

## 起点

从承认常识、经验和单一解释在复杂问题里会失灵开始。

## 核心转向

从“会用模型”升级到“会比较、组合并切换多个模型”。

## 最终落点

落到一种更稳的判断动作：先判断问题类型，再选择模型，再让多个模型彼此校正。

## 章节推进

Part 1：为什么需要模型思维，先建立“复杂世界不能只靠常识”的问题意识。；Part 2：模型的7大用途，把模型从预测工具扩展成认知工具箱。；Part 3：多模型思维，说明为什么复杂问题必须依赖模型组合。；Part 4：对人类行为者建模，把视角从静态现象推进到激励、互动、学习和网络。；Part 5：模型工具箱与现实应用，把分布、随机过程、路径依赖和系统动力学整理成现实问题的观察维度。

## 必须保留的概念

- 模型
- 多模型思维
- 智慧层次结构
- 模型的7大用途
- 激励
- 博弈与战略互动
- 网络
- 分布
- 路径依赖
- 反馈
- 系统动力学

## 必须保留的关系

- 常识和单一解释 -> 在复杂问题中失灵 -> 需要模型介入
- 模型 -> 让现象可推理、可比较、可校正
- 模型用途不同 -> 评价模型好坏的标准不同
- 单一模型 -> 视角锋利但盲区更大
- 多模型 -> 互补、比较、校正 -> 判断更稳健
- 激励 -> 行为选择 -> 群体结果
- 网络结构 -> 信息与影响扩散 -> 结果放大或扭曲
- 早期差异 -> 积累 -> 锁定 -> 路径依赖
- 反馈 + 延迟 -> 系统反弹或失控
- 先判题型 -> 再选模型 -> 最后组合模型
