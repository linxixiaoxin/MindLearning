# 全书结构

## 主问题

《斯坦福大学人生设计课》如何帮助读者把成长愿望拆成可练习、可反馈、可持续的行动系统。

## 一句话结构

目标 -> 方法 -> 练习 -> 反馈 -> 身份变化

## 核心对象

学习、时间、习惯、成长和行动

## 章节推进

- 分析测评你目前的生活
- 就这4个方面的情况写几句话
- 在每个仪表盘上标出你的位置(0~完美)
- 在这4个方面,你是否存在需要解决的问题
- 你的问题是不是一个“重力问题”?
- 创建人生的指南针
- 写一小段工作观反思,大约需要30分钟,250字左右,不要超过一页纸
- 写一小段人生观反思,大约需要30分钟,250字左右,不要超过一页纸
- 多读几遍你的工作观和人生观,然后回答下面的问题
- 寻路
- 连续记录三周
- 在每个周末记录下你的感想。注意,一定记录清楚哪个活动吸引了你、让你感兴趣,哪个活动让你感到无聊
