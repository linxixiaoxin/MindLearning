# 全书结构

## 主问题

《唤醒老虎：启动自我疗愈本能》如何帮助读者理解内在模式、情绪反应和关系中的自我位置。

## 一句话结构

情绪感受 -> 内在模式 -> 关系边界 -> 自我修复

## 核心对象

情绪、身体、关系、自我模式和意义

## 章节推进

- 分：创伤的症状——这一部分对创伤反应、创伤症状及心理受创者忍受的现实等里面的核心要素进行了更深入的阐述
- 分：转化——描述了我们转化自身心理创伤治疗的过程，无论这种创伤是个人型的还是社会型的
- 分： 把你在之前三部分练习中写下的答案放在一起比较。你在每种情境下做出的反应有何相似之处？
- 过度反应
- 收缩
- 解离
- 僵呆（僵直），常伴有绝望无助感
- 意识与身体
- 部分身体，比如头或四肢，与身体其他部分
- 自我和情感、想法或感觉
- 自我和对事件的部分记忆或者全部记忆
