# 全书结构

## 主问题

《日常生活中的自我呈现》需要回答的是：互动场景、角色、观众、前台/后台与印象管理如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“互动场景 -> 角色期待 -> 前台/后台 -> 印象管理 -> 尴尬修复 -> 身份风险”入库，从互动场景、角色、观众、前台/后台与印象管理出发，保留概念、机制、场景、证据和误用边界。

## 起点

不要从“我该怎么做”进入，而要先看互动场景、角色、观众、前台/后台与印象管理在原书中怎样成为问题。

## 核心转向

关键转折是把读者从个人感受带回互动场景、角色、观众、前台/后台与印象管理背后的结构、媒介、空间、制度或互动机制。

## 最终落点

形成可复用的后台判断语言，再谨慎转成前台内容主题。

## 章节推进

- 表演：用表演确定这本书进入问题的入口，先钉住互动场景、角色、观众、前台/后台与印象管理的出场条件。
- 剧班：把剧班作为分析对象的转折点，观察互动场景、角色、观众、前台/后台与印象管理如何从背景变成可描述的结构。
- 区域与区域行为：通过区域与区域行为整理关键概念之间的压力，避免把本章读成孤立观点摘录。
- 不协调角色：借不协调角色补足证据层，让互动表演 / 角色场景型不只停留在术语解释。
- 角色外的沟通：以角色外的沟通收束前面章节留下的边界问题，给后续主题 K 提供判断语言。
- 印象管理艺术：用印象管理艺术确定这本书进入问题的入口，先钉住互动场景、角色、观众、前台/后台与印象管理的出场条件。

## 必须保留的概念

- 前台
- 后台
- 印象管理

## 必须保留的关系

- 互动场景、角色、观众、前台/后台与印象管理不是个人感受的同义词，必须放回原书对象关系中理解。
- 互动表演 / 角色场景型文本不能被压缩成普通方法书。
- 前台内容可以转译，后台结构不能丢失。
