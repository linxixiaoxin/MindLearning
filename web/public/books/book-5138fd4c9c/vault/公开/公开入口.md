# 疯癫与文明

## 这本书先解决什么

《疯癫与文明》需要回答的是：疯癫、理性、禁闭与医学凝视如何在现代生活、知识秩序或社会互动中被组织出来，并影响人的自我理解？

## 一句话结构

这本书应按“历史问题化 -> 分类/命名 -> 制度装置 -> 话语规则 -> 身体/主体变化 -> 当代边界”入库，从疯癫、理性、禁闭与医学凝视出发，保留概念、机制、场景、证据和误用边界。
