# 为什么疯癫、理性、禁闭与医学凝视不能只当成个人问题

## 切入类型

理论母书转译

## 读者痛点

把结构性压力误读成个人失败。

## 覆盖范围

全书

## 核心矛盾

疯癫、理性、禁闭与医学凝视不是个人感受的同义词，必须放回原书对象关系中理解。

## 必须保留的概念

- 大禁闭
- 医学凝视
- 正常/异常划分

## 必须保留的关系

- 疯癫、理性、禁闭与医学凝视不是个人感受的同义词，必须放回原书对象关系中理解。
- 谱系权力 / 话语制度型文本不能被压缩成普通方法书。
- 前台内容可以转译，后台结构不能丢失。

## 页面结构建议

真实场景 -> 理论对象 -> 机制解释 -> 可承受转译

## 为什么有效

这个选题保留了原书分析对象和现实入口，适合从后台理论转成前台可理解主题。
