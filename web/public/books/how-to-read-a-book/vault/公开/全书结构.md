# 全书结构

## 主问题

《如何阅读一这本书》如何帮助读者把成长愿望拆成可练习、可反馈、可持续的行动系统。

## 一句话结构

目标 -> 方法 -> 练习 -> 反馈 -> 身份变化

## 核心对象

学习、时间、习惯、成长和行动

## 章节推进

- 阅读的层次
- 阅读的活力与艺术
- 阅读的第一个层次:基础阅读
- 阅读的第二个层次:检视阅读
- 如何做一个自我要求的读者
- 阅读的第三个层次:分析阅读
- 一这本书的分类
- 透视一这本书
- 与作者找出共通的词义
- 判断作者的主旨
- 公正地评断一这本书
- 赞同或反对作者
